# What

Zoom buttons on the top bar — the text smaller, larger.

# Design

## text-zoom

- the bar's right end: `A↓`, the percentage — a press resets it, `A↑`
- steps 50%–200%, as a browser's
- CSS `zoom` on each top-level block — text, boxes, images alike; the page's padding stays
- `localStorage`, `maden.ui.textZoom` — as the other appearance settings
